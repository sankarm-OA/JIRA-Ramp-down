# Replace Tempo with a native or equivalent time-tracking and effort-logging capability in the target platform(s), preserving cost-centre and Finance reporting

## Release Information

**Product/Module:** Frontier Toolset (OneStack Roll Out)
**Version:** 1.0

## Headline

Native time-tracking and effort-logging replaces Tempo, consolidating scheduling, costing, and L\&D reporting in a unified platform.

## Summary

This release eliminates the external Tempo dependency by introducing native time-tracking and effort-logging capabilities built directly into the target platform. The solution preserves all cost-centre allocation and learning & development reporting functionality while streamlining workflows and reducing integration overhead. Users gain a single system for scheduling, tracking effort, and generating compliance and performance reports.

## Problem Statement

Organizations currently rely on Tempo as an external tool for time-tracking and effort-logging, creating operational fragmentation—data lives in separate systems, integrations are complex and brittle, and cost-centre and L\&D reporting requires manual reconciliation across platforms. This adds friction to daily workflows, increases maintenance burden, and creates audit and accuracy risks.

## Solution

We are introducing a native time-tracking and effort-logging module directly within the target platform that mirrors and extends Tempo's core functionality. The solution captures time entries, allocates effort against cost centres, tracks learning & development activities, and generates consolidated reporting—all within a single system. This eliminates third-party dependencies, simplifies data architecture, and enables real-time visibility into resource utilization and learning investments.

## Key Features

* Native time entry and effort-logging interface with inline cost-centre allocation
* Automated cost-centre reporting with multi-level drill-down and variance analysis
* Learning & development activity tracking linked to employee development plans and compliance requirements
* Batch and real-time reporting exports for payroll, finance, and HR systems
* Historical data migration from Tempo with validation and reconciliation checks
* Role-based access controls and audit trails for compliance and governance

## Customer Benefits

* Unified system eliminates context-switching and manual reconciliation across tools
* Real-time visibility into resource utilization, project costing, and L\&D investment
* Reduced operational complexity and maintenance overhead from external tool management
* Preserved reporting accuracy for cost allocation, budget tracking, and learning compliance
* Faster time-to-insight through consolidated dashboards and native integrations
