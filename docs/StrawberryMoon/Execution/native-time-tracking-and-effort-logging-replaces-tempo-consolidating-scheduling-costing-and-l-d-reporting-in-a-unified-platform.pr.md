# Press Release

## Release Information

**Product/Module:** Engineering Operations & Financial Governance
**Version:** 1.0.0

## Headline

Automated AI Effort Attribution: Seamlessly Capturing Developer and Agentic Work for Audit-Ready R\&D Capitalization

## Summary

We are introducing an automated tracking and attribution framework that measures engineering effort across human developers and autonomous AI agents. This release correlates IDE telemetry, PR metadata, and AI agent token usage directly to strategic product epics, enabling finance and engineering leaders to accurately capitalize software development investments under IFRS/GAAP standards without introducing administrative overhead.

## Problem Statement

The rapid adoption of AI coding assistants and autonomous agents has decoupled traditional engineering time tracking (hours logged, developer headcount) from actual software delivery output. Engineering and finance teams struggle to quantify, attribute, and audit development effort spent on capitalizable new features versus non-capitalizable maintenance, creating regulatory compliance risks and underreported R\&D capitalization assets.

## Solution

An end-to-end telemetry and attribution engine that automatically captures, tags, and rolls up human and agentic development effort by feature branch, ticket metadata, and repository commits. The system translates multi-modal contributions (human code reviews, AI code generation, automated agent refactoring) into auditable effort units aligned with accounting standards.

## Internal Notes

* Requires alignment with external audit partners on agentic runtime-to-effort equivalence models.
* Initial rollout targets GitHub Actions, Cursor/Copilot telemetry, and Jira Epic taxonomies.
* Front matter and reporting must support both standard developer rates and blended compute/token cost models.
