# Stand up Strawberry Moon and OneStack with the project structures, workflows, fields and permission model needed to receive migrated data and run live sprints

## Release Information
**Product/Module:** Frontier Toolset (OneStack Roll Out)
**Version:** 1.0

## Headline
Strawberry Moon and OneStack launch with foundational project infrastructure ready for data migration and live sprint execution.

## Summary
Strawberry Moon and OneStack are now live with fully configured project structures, workflows, custom fields, and permission models designed to receive migrated data from legacy systems and support live sprint operations. Teams can immediately begin importing historical data and running collaborative sprints within a unified, governed environment.

## Problem Statement
Teams managing work across multiple legacy systems lack a unified platform that can receive complex migrated data while maintaining governance, permissions, and workflow continuity. Without proper project structure configuration upfront, data import becomes fragile, permissions are misconfigured post-import, and sprint execution is delayed by infrastructure gaps.

## Solution
Strawberry Moon and OneStack provide pre-configured project scaffolding, flexible workflow definitions, extensible custom fields, and granular permission models that accommodate legacy data shapes and enable immediate sprint readiness. The foundational setup eliminates post-import rework and allows teams to focus on execution rather than platform remediation.

## Key Features
- Pre-built project structures supporting multiple team topologies and work hierarchies
- Configurable workflows that map legacy process states to modern sprint cadences
- Custom field schema supporting legacy data attributes and modern team requirements
- Granular permission model with role-based access control scoped to project, team, and artifact levels
- Data import pipeline designed to accept and transform legacy field mappings without loss of fidelity
- Live sprint templates with preconfigured ceremonies, capacity planning, and burndown tracking

## Customer Benefits
- Migrate historical data without rework or post-import field remapping
- Start running live sprints immediately after data import completes
- Maintain governance and security posture throughout migration and ongoing operations
- Reduce time-to-productivity by eliminating infrastructure and configuration delays
- Scale team collaboration across multiple projects with consistent, repeatable structures
